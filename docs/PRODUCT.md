# LearnOS · 个人学习操作系统 — 产品设计文档（PRD v1.0）

> 从「CDMP 单认证工具」演进为「通用学习平台」：以**轨道（Track）**为核心抽象，
> 一轨 = 一门认证/技能的完整学习闭环。本文档是产品与技术的总设计，随版本演进。

---

## 1. 产品定位与愿景

**一句话定位**：私人所有的学习操作系统——每一门想拿下的认证或技能，都是一个"轨道"；
平台提供统一的 计划 → 精讲 → 刷题 → 模考 → 复盘 闭环引擎。

- **不是**在线课程市场（不做视频托管、不做社区）
- **是**结构化学习引擎 + 私有知识库 + 考试模拟器，数据完全归用户所有

**愿景指标**：三年内承载 5+ 条轨道（CDMP / PMP / CKA / Java / Go），成为用户所有
"要考/要学"事项的默认入口。

## 2. 目标用户与核心场景

| 用户 | 场景 | 关键诉求 |
|---|---|---|
| **所有者（主用户）** | 同时推进多张认证（CDMP→PMP→CKA）与技能（Java/Go） | 多轨道进度互不干扰；一个入口看全局 |
| **受邀学习者** | 通过访问密码进入学习 | 免注册、进度本地保存、界面零学习成本 |
| **未来（L2/L3）** | 公开/团队学员 | 独立账号、跨设备同步、学习数据归属自己 |

## 3. 信息架构（IA）

```
登录门禁（内容加密保险库）
└── 轨道中心 Hub  ──────────────── #/hub
    ├── 全局统计：进行中轨道 / 累计刷题 / 错题 / 模考
    ├── 轨道卡片（active）：进度环 + 继续学习
    └── 轨道卡片（coming soon）：建设中占位
└── 轨道内 Space  ──────────────── #/<trackId>/<view>
    ├── home      学习首页（轨道级仪表盘 + 下一步行动）
    ├── plan      学习计划（N 天冲刺，逐日勾选 + 考试日期倒计时）
    ├── knowledge 知识体系（知识域 → 摘要/考点/术语/必背）
    ├── quiz      章节刷题（按章 / 随机 / 错题重练 / 真题专区）
    ├── exam      模拟考试（计时 / 标记 / 评分 / 章节诊断 / 成绩历史）
    ├── resources 资料纳管（分级目录 + 学习状态）
    └── tips      备考攻略（考试速览 / 策略 / 记忆法）
全局：顶栏轨道切换器 · 🔒 退出 · （规划中）设置中心
```

**URL 即状态**：`#/cdmp/quiz`、`#/pmp/plan`——可直达、可收藏、可未来做深链同步。

## 4. 核心领域模型

```
Platform
 ├─ tracks: Track[]            # 已上线轨道
 ├─ comingSoon: TrackMeta[]    # 占位轨道（建设中）
 └─ general: { miniappCost… }  # 平台级通用内容

Track（轨道内容包，纯数据、可加密、可版本化）
 ├─ meta:      { id, name, full, icon, color, tagline, heroTitle, status,
 │               exam: { questions, minutes, pass, target, stretch, pace, chips } }
 ├─ knowledge: KnowledgeArea[] # { id, name, icon, color, weight, brief, summary,
 │                             #   points[], terms[{term,def}], mustKnow }
 ├─ bank:      Question[]      # { id, ch, q, opts[4], ans, exp }
 ├─ realBank:  Question[]      # 真题（本地导入，set=试卷名，ch 可空）
 ├─ plan:      { totalDays, weeks[{ week, theme, days[{day,title,ch,tasks}] }] }
 ├─ resources: { privacy, cats[{ id, name, items[{id,icon,name,type,size,path,stars,note}] }] }
 └─ tips:      { examFacts[], strategy[], memory[] }

Progress（每用户 × 每轨道，localStorage / 未来云同步）
 └─ { checks{}, chStats{}, wrong[], exams[], resStatus{}, examDate, termsRead{} }
```

**设计原则**：
1. **内容与引擎分离**——引擎（刷题/模考/计划/进度）只认上面的接口；换一条轨道，引擎零改动。
2. **进度与内容解耦**——进度按 `trackId` 隔离存储，删轨道不丢历史，加轨道不影响旧进度。
3. **真题与题库分池**——`bank`（自研）与 `realBank`（导入）独立统计，错题本统一。

## 5. 轨道内容包规范（新增 Java / PMP / CKA 的标准动作）

新增一条轨道 = 交付一个内容包，共 6 件套：

| 件 | 建议规模 | 说明 |
|---|---|---|
| `meta` | — | 名称/图标/主色/考试信息（题量、时长、及格线、目标分） |
| `knowledge` | 8–20 个知识域 | 每域：摘要、5-8 条高频考点、5-7 个术语、一句话必背 |
| `bank` | **≥100 题**（带解析） | 按知识域分布，权重高的域题量加倍 |
| `plan` | 30–90 天 | 每日任务与知识域绑定，周复盘 + 模考节点 |
| `resources` | 10–40 条 | 分级：核心备考 / 经典书 / 专题深化 / 行业视野 |
| `tips` | — | 考试速览、答题策略、8 条记忆法 |

**文件约定**：`data/track-<id>.js` 组装器 + 若干分片文件，全部注册到
`window.TRACKS.<id>`；随后 `CDMP_PASS=… node tools/encrypt-data.mjs` 重新打包保险库。
（占位轨道只需在 `platform.js` 的 `comingSoon` 里登记。）

## 7. 前端架构

- **形态**：零依赖原生 SPA（hash 路由），壳层与轨道内容全部静态资源；经典脚本 + `LearnOS`
  命名空间（保留 file:// 双击可用，不引入打包器）。
- **模块分层**（v2.2）：
  - `js/core.js` — 纯函数域逻辑（作答/统计/错题本/活动洞察/搜索/状态迁移），
    浏览器与 Node 双端可用（`module.exports` 守卫），`node --test tests/` 覆盖；
  - `js/crypto.js` — 门禁加解密（PBKDF2 + AES-256-GCM），同样双端可测；
  - `js/app.js` — 壳层：路由、视图渲染、快捷键、门禁交互（纯 DOM，无业务规则）。
- **安全层**：内容打包为 AES-256-GCM 加密保险库（`data/vault.js`），密钥由访问密码
  PBKDF2(310k) 派生，浏览器端 Web Crypto 就地解密；明文永不入库、不上服务器。
- **构建**：`tools/encrypt-data.mjs` 自动发现 `data/*.js` 分片（platform 最先、track-* 最后），
  输出保险库 + `data/content.sha256` 哈希清单；`npm run check` 防"改数据忘重打包"。
- **CI**：GitHub Actions —— 语法检查、node:test 单测、仓库卫生（明文数据不入库、保险库无明文标记）。
- **状态机**：`Platform(只读) × Progress(读写)`；进度写入即持久化（localStorage），
  视图函数均为 `(Track, Progress) → DOM` 的纯渲染。
- **扩展点**：新轨道=新数据包；新题型（多选/判断/案例）= 引擎加渲染分支，数据结构向前兼容。
- **下一阶段**：视图层组件化拆分（app.js 仍为最大文件）、进度端到端加密导出、PWA 离线。

## 8. 后端演进

| 级别 | 架构 | 数据归属 | 成本 |
|---|---|---|---|
| **L1 本地模式** | GitHub Pages 静态托管 + 加密保险库 + localStorage | 用户浏览器 | 0 元 |
| **L2 云端模式（v3.0 已交付）** | 自建零依赖 Node API（scrypt 账号体系 + HttpOnly 会话 + track 粒度 LWW 同步 + 限流 + 严格 CSP）+ 前端双模式自动切换；Docker/系统部署 | 用户账号 | 服务器 ¥30-100/月（小规格可免费） |
| **L3 平台化** | 对象存储（资料私有桶 + 签名 URL）+ 管理后台（轨道 CMS）+ 支付/会员；大陆访问需备案域名 | 平台托管 | ¥100-500/年起 |

**同步策略（L2 预研结论）**：进度 payload 以 track 为粒度整体上云，`updated_at` 撮合
last-write-wins；`wrong[]` 与 `exams[]` 做并集合并，避免多端互踩。

## 9. 数据与隐私原则（不可妥协）

1. 不做埋点、不接第三方统计；页面无任何外部请求。
2. 内容加密分发，密码/明文不出现在仓库与提交历史。
3. 学习数据默认本地；上云前必须先给"一键导出/删除"。
4. 真题等版权敏感内容仅存本地或密文分发，永不以明文形式公开。

## 10. 度量（北极星与护栏）

- **北极星**：周学习天数（周内有打卡/刷题行为的天数）。
- 支撑指标：计划完成率、题库覆盖率、模考达标率（≥target 分）、错题复活率。
- 护栏指标：解锁→首次刷题转化（新轨道易用性）、单次会话时长（防疲劳设计依据）。

## 11. 风险与对策

| 风险 | 对策 |
|---|---|
| 真题版权 | 仅本地/密文分发（现状即如此）；L2 起改为私有对象存储 |
| 弱密码穷举 | README 明示；提供一键换密码重打包；L2 换真账号体系 |
| 单轨道内容过期 | 轨道包带版本字段，引擎提示"内容更新" |
| 浏览器数据丢失 | M2 提供 JSON 导出/导入；L2 云同步根治 |
