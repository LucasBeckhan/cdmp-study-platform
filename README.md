## 🔒 隐私说明（先读这个）

- **纯静态、零后端、零埋点、零第三方请求**：页面所有资源本地加载，不向任何服务器发送数据。
- 学习进度（计划勾选、刷题统计、错题本、模考成绩、资料状态）**仅存于浏览器 localStorage**，清除浏览器数据即重置。
- 学习内容打包为**加密保险库**（AES-256-GCM，密钥由访问密码经 PBKDF2 派生）：仓库与线上只有密文，访问密码不出现在任何代码或请求中。
- 资料目录与真题数据**不含任何来源信息**：来源渠道、链接、访问凭据、原始路径一律不出现在代码、页面与提交历史中。
- 全部明文数据文件均**不入 Git 仓库**（`.gitignore`），仅保留在维护者本地；仓库与线上只分发加密保险库。

## 🔐 访问门禁（已启用）

首次访问需输入**访问密码**解锁；可勾选「记住此设备」免重复输入，右上角 🔒 退出 可随时重新上锁。

- 这是**真加密而非摆设**：全部学习内容（知识体系、题库、计划、攻略）打包为 AES-256-GCM 加密保险库 `data/vault.js`，密钥由访问密码经 PBKDF2（310,000 次迭代）派生——密码错误 = 解密失败 = 内容不可读，内容明文与密码都不存在于仓库和页面中。
- **修改访问密码**：`CDMP_PASS=新密码 node tools/encrypt-data.mjs`，然后提交更新后的 `data/vault.js`。
- **安全提示**：弱密码可被离线穷举。个人小圈子使用可接受；正式对外建议 10 位以上混合密码。

## 🚀 快速开始

**在线使用（推荐）**：直接访问 GitHub Pages 线上地址（仓库 Settings → Pages 已开启 `main` 分支根目录）。

**本地使用**：

```bash
git clone https://github.com/LucasBeckhan/cdmp-study-platform.git
cd cdmp-study-platform
# 任选一种方式启动静态服务
python3 -m http.server 8080
# 或 npx serve .
# 浏览器打开 http://localhost:8080
```

纯静态站点（HTML + CSS + 原生 JS），零依赖、零构建、零后端。

## 🏆 真题题库（本地导入）

将本地真题 xlsx 放入 `_import/` 目录（已被 `.gitignore` 排除），运行解析器生成真题题库，即可在平台内练习：

```bash
python3 -I tools/parse_real_xlsx.py _import/*.xlsx -o data/questions-real.js
```

- 「章节刷题」页自动出现 **🏆 真题实战专区**：按套限时练习 / 真题混合练习
- 「模拟考试」可切换抽题来源：知识域题库 / 真题卷
- 真题错题同样进入错题本；真题数据仅保留本地，未经确认不推送公开仓库

## 💰 常见问题：做成小程序需要额外费用吗？

**当前网页版 = 0 成本**（GitHub Pages 免费托管）。若未来要做微信小程序：

| 项目 | 网页版（本平台） | 微信小程序 |
|---|---|---|
| 平台本身 | GitHub Pages / Vercel **0 元** | 个人主体注册免费；企业主体微信认证 **¥300/年** |
| 域名与备案 | 免费二级域名即可 | 必须备案域名（¥30-80/年）+ HTTPS |
| 服务器 | 纯静态无需服务器 | 需 HTTPS 服务器（轻量云 ¥100-300/年） |
| 支付能力 | 不涉及 | 需企业主体 + 微信支付商户号；iOS 虚拟支付受限 |
| 开发成本 | 已就绪 | 可用 uni-app/Taro 复用本平台代码（约 1-2 周） |

**结论**：个人使用/团队分享，网页版就是最优解；若确需小程序，个人主体 + 免费注册即可承载刷题功能（0 额外费用），带认证发布则首年约 ¥500-700。
